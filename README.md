# bachelor_thesis_schultes
This GitHub repository contains the codes and pipeline I used for the analysis of my data in my bachelor thesis. Codes in R and python were created with the use of the AI tool Claude Code (Anthropic)

01_pipeline: FIJI macros and LUT used for image preprocessing and the ilastik/Nutil cell-counting pipeline (section 2.9) 
02_tractquant: TractQuant python program for automated whole-brain quantification of projection intensity (section 2.8.1) |
03_analysis_R: R scripts for all statistics and figures (sections 2.10, 3.1–3.9), with a figure ↔ script table in its own README |
measurements used for the validation: `validation_TRAP-Cre.csv`, `validation_TRAP-tTA.csv`
